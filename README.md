# RING — ทุกหมัด มีเรื่องราว

โครงงานเว็บไซต์ภาษาไทยสำหรับคนรักศิลปะการต่อสู้ ใช้ Vite และ JavaScript พร้อมระบบบัญชี Express/MongoDB ที่มีอยู่ในโปรเจกต์

## เปิดโปรเจกต์

ใช้ Node.js 22 จากนั้นรันที่โฟลเดอร์หลัก:

```sh
npm install
npm run dev
```

เปิด URL ที่ Vite แสดง (ค่าเริ่มต้น http://localhost:5174) และ build ด้วย `npm run build`

หน้าเว็บอยู่ที่ `client/index.html` ไม่ใช่ไฟล์ ReleaseNotes.html ของ Git

ระบบสมาชิกต้องเปิด backend และตั้งค่า environment ตาม `.env.example` โดย Vite ส่ง `/api` ไป `http://localhost:5000` สามารถดูเว็บและจองบัตรจำลองได้แม้ยังไม่เปิด backend

## ลำดับสาธิตสำหรับส่งอาจารย์

1. เปิดหน้าแรก แสดงแบรนด์ RING และกราฟิกสังเวียนต้นฉบับ
2. ไปที่ซื้อบัตร กดเลือกบัตร เลือก Standard / Premium / Ringside และจำนวน 1–6 ที่นั่ง สังเกตราคารวมที่เปลี่ยนตามตัวเลือก
3. กรอกชื่อสมมติ ยอมรับเงื่อนไขบัตรจำลอง แล้วยืนยัน
4. แสดงบัตร ดาวน์โหลดไฟล์ข้อความ หรือเลือกพิมพ์เพื่อบันทึก PDF ผ่านเบราว์เซอร์
5. โหลดหน้าใหม่ เปิดบัตรของฉันเพื่อแสดงการจัดเก็บข้อมูล
6. กรองคู่ชก ค้นหาชื่อนักกีฬา เลือกมุม ตั้งแต้ม และยืนยัน ดูประวัติการเลือกมุม
7. เปิดโปรไฟล์นักกีฬาจากลิงก์ทางการ อ่านบทความ และเปิดที่มาของโครงงานจากส่วนท้าย
8. แสดงการปรับหน้าจอบนมือถือ เมนูมือถือ และการใช้งานด้วยคีย์บอร์ด

## ขอบเขตระบบ

- บัตรเป็นการจอง **จำลอง** สำหรับ RINGSIDE SESSIONS ซึ่งเป็นงานสมมติ นักกีฬาในเว็บไซต์ไม่ได้ร่วมงาน ไม่มี payment gateway ไม่มีการสำรองที่นั่งจริง และไม่มีอีเมลยืนยัน
- บัตรไม่มีมูลค่า ใช้เข้างานจริงไม่ได้ ไม่มีการเก็บข้อมูลบัตรเครดิต
- บัตรและประวัติแต้มเก็บใน localStorage ของเบราว์เซอร์ การล้างข้อมูลจะลบประวัติ ไม่ซิงก์ระหว่างอุปกรณ์หรือบัญชีสมาชิก ใช้ชื่อสมมติระหว่างสาธิตได้
- โซนบัตรเป็นผังสาธิต ไม่มีการเลือกเลขที่นั่ง ระบบหลังบ้านขายบัตรจริงและระบบตรวจบัตรยังไม่รวมอยู่ในโครงงาน
- คู่ชกเป็นจินตนาการ ไม่ใช่ตารางแข่งจริง ไม่มีการสร้างสถิติของนักกีฬาขึ้นเอง แต้มไม่มีมูลค่า ไม่มีผลตัดสินหรือจ่ายรางวัล
- บัญชีสมาชิกเชื่อมต่อ API เดิม การทดสอบแบบไม่เปิดเซิร์ฟเวอร์จะแสดงข้อความว่าระบบสมาชิกไม่พร้อม

## เนื้อหาและที่มา

ออกแบบ UI, SVG สังเวียน (`client/public/images/ring-art.svg`) และบทความขึ้นใหม่ ใช้ภาพนักกีฬาจากหน้าโปรไฟล์ทางการของ ONE Championship ตามคำขอสำหรับโครงงาน พร้อมเครดิตและลิงก์ต้นทาง ภาพเหล่านี้ยังมีลิขสิทธิ์ ไม่ใช่ภาพปลอดลิขสิทธิ์ ไม่คัดลอกโลโก้หรือบทความจากเว็บตัวอย่าง เว็บไซต์นี้เป็นโครงงานอิสระและไม่มีการรับรองจาก ONE หรือนักกีฬา

ชื่อนักกีฬาอ้างอิงจากหน้าโปรไฟล์ทางการ ตรวจสอบ 25 กันยายน 2569:

- https://www.onefc.com/th/athletes/superlek/
- https://www.onefc.com/th/athletes/tawanchai/
- https://www.onefc.com/th/athletes/superbon/

แบบอักษร IBM Plex Sans Thai, Noto Sans Thai และ Barlow Condensed เรียกจาก Google Fonts และมีฟอนต์ระบบสำรองเมื่อออฟไลน์ การอ้างอิงชื่อไม่ได้หมายถึงสิทธิใช้ภาพหรือสิทธิขายบัตรขององค์กรอื่น หากจะนำไปขายบัตรจริงต้องได้รับสิทธิจากผู้จัดและพัฒนาระบบชำระเงิน/สต็อกบัตรบนเซิร์ฟเวอร์ก่อน

## การตรวจสอบ

- Production build ผ่านด้วย Vite
- `scripts/browser-smoke.mjs` ตรวจใน Chrome: จองบัตร/ราคา/ตรวจฟอร์ม, escape ชื่อบนบัตร, บัตรหลัง reload, ค้นหา/กรองคู่ชก, ตรวจแต้ม, ประวัติ, แท็บสมาชิก, บทความ, ข้อมูลเสียใน localStorage และ layout ที่ 320/390/768/1440 px
- รันทดสอบด้วย `node scripts/browser-smoke.mjs` หลังเปิด Vite ที่ port 5174 และ Chrome headless ที่ remote debugging port 9333 **ใช้โปรไฟล์ Chrome แยกสำหรับทดสอบเท่านั้น** เพราะสคริปต์จะล้าง localStorage ของเว็บไซต์ทดสอบ
- การสมัคร/เข้าสู่ระบบกับฐานข้อมูลจริงยังไม่ได้ทดสอบในรอบนี้ เพราะไม่ได้เปิด backend และไม่ได้ตั้งค่าฐานข้อมูล

## ธีม After Dark และภาพนักกีฬา
